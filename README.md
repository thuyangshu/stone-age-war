# 石器大战

石器时代的投掷对战。两名原始人隔着山丘、灌木和池塘轮流投掷石器武器，
抛物线弹道，命中扣血，**先把对方血条打空的人赢**。

- **两种模式**：人机对战（轻松 / 普通 / 硬核三档）+ 本地双人（同屏轮流，带交接遮罩防误触）
- **八件武器**：投石、石矛、石箭、石斧、投石索、回旋镖、火把、巨石——每件一个功能位，限量弹药逼你轮换
- **地形不可破坏**：山丘挡弹道、灌木拦弹丸（矛箭可穿透）、池塘落水无效，但弹丸砸地会留下弹坑焦痕
- **零外部依赖**：双击 `index.html` 就能玩，不联网、不装东西、不用构建步骤

## 怎么玩

双击 `index.html`。开局点「人机对战」或「本地双人」。

| 操作 | 说明 |
|---|---|
| 按住并拖拽 | **弹弓式瞄准**：往哪拖，就从反方向甩出去；拖多远 = 多大力 |
| 松手 | 投掷。拖距不足 24px 视为取消 |
| 点武器槽 | 换武器。灰掉的是打光了的 |
| 右上角按钮 | 暂停 / 静音 |
| Esc | 暂停（切后台会自动暂停） |

拖拽时会显示**轨迹预览虚线**和落点圈，还有力度条。预览走的是和真实弹道
同一套物理，不是近似——但它不含直击判定，所以别指望它告诉你能不能打中人的头。

## 跑测试

```bash
./smoke.sh          # 六步闸门：语法 → 单测 → 资源引用 → 无头浏览器 → 难度分布 → 单文件打包版
```

任一步挂了都会真的挂（不吞退出码）。约 100 秒。想快点跳过打包那步：`SKIP_BUNDLE=1 ./smoke.sh`。

单独跑：

```bash
node --test tests/*.test.js            # 37 条纯逻辑单测（地形 / 弹道 / 伤害 / AI / fuzz）
node tests/browser-smoke.mjs           # 36 条无头 Chrome 冒烟（开局到结算全流程 + 手机触屏）
node tests/bot-playtest.mjs            # 三档 AI 对战 200 局，胜率分布对照验收线
node build.mjs                         # 打包单文件版到 dist/
```

## 单文件版

```bash
node build.mjs     # → dist/石器大战.html 与 dist/stone-fight.html（同一份内容，英文名防中文名乱码）
```

1.27 MB 一个文件，发给别人直接能玩。打包器会拦住外部资源残留、脚本顺序错乱，
并把第三方许可声明整份嵌进文件头。

## 代码结构

```
index.html / style.css     DOM 叠层 + <script src> 顺序加载（file:// 直玩）
smoke.sh / build.mjs       六步闸门；单文件打包
js/data.js                 全部数值表——调平衡只改这一个文件
js/logic.js                纯逻辑：弹道解算、子步积分、碰撞、伤害、AI、回合规则
js/world.js                纯逻辑：地形生成、地表查询、视线遮挡、站位选取
js/game.js                 Phaser 战斗场景：渲染、相机、瞄准输入、粒子、贴花
js/ui.js                   DOM 叠层与流程状态机
js/textures.js             全部美术：程序生成贴图（Canvas 2D 绘制，零图片文件）
js/sfx.js                  ZzFX 合成音效，零音频文件
js/main.js                 启动配置 + window.__debug 自动化接口
vendor/                    Phaser 3.90 + ZzFX（MIT，许可全文见 vendor/LICENSES.md）
```

依赖方向 `data ← world ← logic ← game ← main`。`logic`/`world` 不碰 DOM、canvas、
Phaser，也不调 `Math.random`（随机全走传入的 rng），所以能在 Node 里直接单测，
弹道与地形的回归不依赖浏览器。

**物理不用 Phaser Arcade**：高度场地形做不了解析碰撞，弹道/碰撞/伤害/AI 全在纯逻辑
模块里自研——Phaser 只管表现，规则可单测。这也是本项目能拿 `node --test` 钉死
"高速弹丸不穿模""溅射衰减三点值"这类结论的前提。

## 数值都在 data.js

武器射程、伤害、溅射半径、AI 误差、地形尺寸、相机缩放、回合节奏，全部集中在
`js/data.js`。里面的注释记着每条数值**为什么是这个数**——比如 AI 的误差为什么按
"判定圈边缘"来定：巨石判定圈是 26+16=42px，误差散布比它小的时候三档全落在圈里、
难度分不出来（实测硬核打普通一度只剩 65%，验收线 ≥75%）；误差散布大到圈外，
又会变成乱打。这条注释连带实测数据都留在文件里。
